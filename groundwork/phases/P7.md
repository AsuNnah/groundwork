# P7: Build

Per task, taking the next `todo` task from `.groundwork/tasks.json` whose dependencies are done:
1. For the first task of a feature, create a branch (or git worktree) and confirm the existing tests pass (clean baseline).
2. **Test first** when `test_first`: write the failing test and run it to see it fail.
3. Implement the smallest change that makes it pass. Match the codebase's existing patterns. Add no unrequested features.
4. Run the task's `verify` command. On a build failure, follow the `debugging-and-error-recovery` skill and fix the root cause. Don't weaken tests, linters, or configs.
5. Commit atomically: `type(scope): summary (T01, REQ-001)`.
6. Set the task to `"status":"done"` in tasks.json.

- Large tier: use a fresh subagent per task. Give it the task JSON plus the relevant doc sections, not the whole chat.
- If scope changes: update the PRD/plan first and rerun only the affected phases. A new target or stack means P2+P3 again; a new dependency means P4.
- When all tasks are done: `gw phase P7 done`.
